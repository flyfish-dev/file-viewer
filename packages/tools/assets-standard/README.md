# @file-viewer/assets-standard

[English](https://github.com/flyfish-dev/file-viewer/blob/main/packages/tools/assets-standard/README.md) · [简体中文](https://github.com/flyfish-dev/file-viewer/blob/main/packages/tools/assets-standard/README.zh-CN.md)

Self-hosted assets for the frozen standard profile. It contains only the Workers, WebAssembly modules, fonts, and vendor files required by PDF, DOCX, PPTX, spreadsheets, and archives. CAD, 3D, Typst, iWork, DICOM, and legacy PPT assets are excluded.
