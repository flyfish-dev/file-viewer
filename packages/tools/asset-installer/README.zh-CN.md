# @file-viewer/asset-installer

[English](https://github.com/flyfish-dev/file-viewer/blob/main/packages/tools/asset-installer/README.md) · [简体中文](https://github.com/flyfish-dev/file-viewer/blob/main/packages/tools/asset-installer/README.zh-CN.md)

Internal public helper used by independently versioned capability asset packs. It performs contained, transactional merges and writes per-package SHA-256 receipts. It carries no renderer assets itself.
