# @file-viewer/assets-chm

[English](https://github.com/flyfish-dev/file-viewer/blob/main/packages/tools/assets-chm/README.md) · [简体中文](https://github.com/flyfish-dev/file-viewer/blob/main/packages/tools/assets-chm/README.zh-CN.md)

Self-hosted Worker and Rust/WebAssembly assets for the opt-in CHM renderer. The installer merges files transactionally and records a per-file SHA-256 receipt.

The package and installed `vendor/chm` directory include the Apache-2.0 license, parser provenance, and the complete locked Rust dependency license inventory required for binary redistribution.
