# laz-perf license provenance

The pinned npm package `laz-perf@0.0.7` declares `Apache-2.0` in package.json.
Its published package metadata points to https://github.com/hobuinc/laz-perf.
The npm tarball installed by the frozen workspace does not include a root
LICENSE/COPYING file; the owned-decoder build deliberately rejected that gap.

The adjacent `laz-perf-COPYING.txt` preserves the upstream COPYING license text
and its `Copyright 2022 Rapidlasso, GmbH` notice. Only one line wrap in section
4(d) differs; the whitespace-separated text is identical. No license terms or
copyright attribution are replaced.

- Upstream source: https://github.com/hobuinc/laz-perf/blob/master/COPYING
- Upstream Git blob: `e597d1debd4e93b10254bcdab301c3b5929753b4`.
- Retained SHA-256: `94b3c7e58be58920c5e87a3d9e21f7eef27fc0dea833075ae4547ebae3ce7d51`.
- Metadata verified from: https://app.unpkg.com/laz-perf@0.0.7/files/package.json

The build accepts this fallback only for the exact name, version and declared
license above and verifies the retained bytes before copying them. Other
missing package licenses still fail the build. The build and asset copier do
not download license text or software. The generated Worker manifest lists
bundled dependencies and their retained license files.
