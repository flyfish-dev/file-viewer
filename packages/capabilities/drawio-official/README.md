# @file-viewer/capability-drawio-official

[English](https://github.com/flyfish-dev/file-viewer/blob/main/packages/capabilities/drawio-official/README.md) · [简体中文](https://github.com/flyfish-dev/file-viewer/blob/main/packages/capabilities/drawio-official/README.zh-CN.md)

Explicitly enables the large same-page diagrams.net viewer. Without this package, Draw.io files use File Viewer's bounded local SVG fallback. Keep this capability opt-in and review its same-page security boundary before deployment.
