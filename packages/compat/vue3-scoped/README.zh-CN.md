# @flyfish-group/file-viewer3

这是 Flyfish File Viewer 的 Vue3 历史兼容包。新项目建议优先使用标准包 `@file-viewer/vue3`；该包继续保持 npm 版本连续，方便已接入 `@flyfish-group/file-viewer3` 的项目平滑升级。

完整文档见 [doc.file-viewer.app](https://doc.file-viewer.app/)。
