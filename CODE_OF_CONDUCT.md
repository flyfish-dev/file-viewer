# Code of Conduct

[English](#code-of-conduct) · [简体中文](#中文说明)

This project welcomes developers from every background. Keep discussions focused on the problem,
the reproduction, design trade-offs, and maintenance cost.

## We encourage

- Clear descriptions of the problem and the environment
- Respect for different tech stacks, deployment constraints, and business contexts
- Reproducible evidence for compatibility boundaries
- Explaining the impact and the expected behavior when criticizing an implementation
- Helping new users find the documentation, the demo, and known issues

## We do not accept

- Personal attacks, mockery, harassment, or discrimination
- Publishing other people's private information or sensitive business files in public issues
- Repeated spamming, pressuring maintainers, or unrelated promotion
- Demanding unrealistic format-fidelity commitments while refusing to provide reproduction details

Maintainers may edit, hide, or close content that violates this code of conduct. In serious cases,
maintainers may restrict further participation.

Report harassment or a conduct concern privately to `admin@flyfish.dev`. Include links or a
description when safe; do not repost private information. If the concern involves that contact,
use GitHub's platform reporting tools. Participation does not require fluency in English: avoid
slang that excludes others, explain abbreviations, and clarify translation ambiguities respectfully.

## 中文说明

遇到骚扰或行为准则问题，请私下联系 `admin@flyfish.dev`，在安全的前提下提供链接或描述，不要再次公开
隐私。若问题涉及该联系人，可使用 GitHub 平台的举报工具。参与不要求英文流利；避免排斥他人的俚语，
解释缩写，并尊重地澄清翻译歧义。

这个项目欢迎来自不同背景的开发者参与。请把讨论集中在问题、复现、设计取舍和维护成本上。

### 我们鼓励

- 清晰描述问题和环境
- 尊重不同技术栈、部署约束和业务场景
- 对兼容性边界给出可复现证据
- 在批评实现时同时说明影响和预期行为
- 帮助新用户定位文档、Demo 和已知问题

### 我们不接受

- 人身攻击、嘲讽、骚扰或歧视
- 在公开 issue 中发布他人的隐私信息或敏感业务文件
- 反复刷屏、催促维护者或无关推广
- 要求项目承诺不现实的格式还原度，却拒绝提供复现信息

维护者可以编辑、隐藏或关闭违反本准则的内容。严重情况下，维护者可以限制继续参与。
