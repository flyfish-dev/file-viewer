# OFD 页面适配精度与原样布局复测

## 修复

页面适配比例原先保留一位小数，向上取整时页面反而超出可用宽度。C002 在传入 850 px 时可用宽度为 840 px，旧代码生成 851 px 页面。现在保留比例完整精度，页面与内容共用同一缩放；保留已有的最大倍率限制，不改变原稿坐标。

## 原样验收

以 SHA-256 识别 C002、C003、C004、C062、C063、C065 共 6 份原稿、17 页，分别在 850 px 和 320 px、DPR 2 下渲染，共 34 次逐页核对。参考模型由原 ZIP 内 XML 独立读取，不使用渲染器的解析结果作为唯一预期。

- 按 Document.xml 的声明顺序核对所有页 ID；C065 明确保持 1 到 10，未按 ZIP 项顺序排列。
- 核对 997 个原始 TextCode 的完整文本、Boundary、X/Y、DeltaX/DeltaY 和 CTM。包含两处前导空白年份，不裁剪空格、不合并独立文字运行。
- 对 C065 的 34 个中点逐一检查实际页面截图中的非空像素，不只判断 DOM 存在。C003 的路径字形保留所有原始二次曲线命令。
- 46 张图片全部解码，未发现外部 HTTP 请求或未处理浏览器错误；C062/C065 的印章图像可见。C002 左下文字、C004 印章周围的红方框反馈与原截图逐项检查，当前未复现缺失/额外红框。

本轮把原样页序、文字坐标、前导空白、中点和图片加载子项标记为已验收；当前已正常的行为不计作新增修复。印章外观不等于验签，未验证签名有效性；上述结果也不是全文字体与桌面阅读器逐像素一致的承诺。

## 执行

```sh
node packages/renderers/ofd/scripts/verify-page-fit.mjs
OFD_SAMPLE_DIRECTORY=/path/to/extracted/package node packages/renderers/ofd/scripts/verify-original-layout.mjs
```

第一条为 25 组纸张/视口适配检查。第二条必须提供全部 6 份哈希匹配的原文件，缺件直接失败；原文件不会上传，也不在报告中写入原始名称和内容。可设置 `OFD_CAPTURE_PAGES=1` 留存本地逐页截图。原稿几何容差为 CSS 序列化的 0.02 px，文字推进/矩阵容差为 0.002。

OFD 包构建及既有六套资源、图像、嵌套块、绘制顺序、翻页与空白回归均通过。没有运行时依赖、版本或锁文件变化。回退本次比例精度修改即可恢复旧行为，不需数据迁移。
