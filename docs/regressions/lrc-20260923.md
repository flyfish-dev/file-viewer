# LRC 格式注册与静态歌词预览

## 结项范围

T01 的“能够预览 LRC 文件”已实现：共享格式表、文本能力清单和预设路由同步增加
`.lrc`，不只依赖后缀回退。提供时间标注、纯歌词、原文三个视图，逐行／逐词时间、
一行多标签、角色继承、元数据、偏移、编码、缩放和换行均有检查。

不播放音频，不承诺外部音轨同步。格式化视图不执行 HTML；未知标签保持文字。
原文保留解码后的完整内容；超大输入或过量标签回退至已有原文渲染器，不静默截断。

  真实 bundle，不依赖外部演示地址；四种语言、Shadow DOM、资源清理和编码均检查。
