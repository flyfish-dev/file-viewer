# DOCX 日期轴、坐标轴标题与组合图

## 根因和修复

日期缓存保存的是日期序号，而分类标签渲染把它直接当成普通文字；折线图也按数组下标等距放置，忽略实际日期间隔。主标题使用递归搜索，误取坐标轴单位标题；多图表组只渲染第一组，丢失组合图中的次坐标轴折线。

修复按组内 axId/crossAx 解析对应坐标轴；日期轴以原始序号计算连续位置，保留稀疏索引、缺项断点、1900/1904 日期系统、UTC 日期格式、月/日主刻度、原稿最小/最大值和反向坐标轴。标签格式中未知的语言或条件语法不猜测，保留原值。数值主刻度有边界限制，异常轴范围不能生成无限坐标或无限循环。

主标题只读取 chart 的直接 title；坐标轴标题保留富文本运行拼接和原稿显式手动位置。柱形＋折线组合按各自绑定的数值轴绘制，不再只显示第一组；分类轴与日期轴保持各自的位置语义，百分比数值轴保留基本格式。只对已支持且轴关系完整的非堆积柱/折线组进入该路径。主题复杂填充、对数轴、曲线插值以及其他高级组合不据此宣称新增支持。

改动采用仓库既有的构建期方法转换，重新生成标准 pnpm 补丁，更新五个引擎入口和演示站 Worker 缓存身份；不是页面运行时替换原型，也没有修改输入文件或新增运行时依赖。没有上游 TypeScript 源码构建完成的声明。
