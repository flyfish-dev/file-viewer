# Word 纵向合并区域的底边框

## 根因与修复

解析引擎保留每个原始单元格，将纵向合并的后续单元格隐藏，并把可见起始单元格设为 `rowspan`。末行的底边框已经解析，但仍留在隐藏的续接单元格上，起始单元格保留的是内部无边框，导致整个合并区域的底边线消失。

新增布局规范化步骤按原始逻辑列网格检查完整合并链。隐藏续接格仍计入列跨度；只有所有中间行、终止行、列跨度和行组都匹配时，才把终止格已解析的底边框转移到可见起始格。保留点值单位、颜色、线型、优先级及显式 `none`，不复制中间行的内部横线，不改变其他三条边、文字、合并属性或表格结构。没有终止边框声明时不虚构边线。

嵌套表格独立处理；普通 HTML rowspan、不完整链、缺失占位格、跨行组、隐藏行、列跨度冲突及越界跨度不作猜测。重排、缩放和导出克隆可重复执行，不积累修改。无公共 API、依赖、锁文件、原文件或 Worker 变更。
