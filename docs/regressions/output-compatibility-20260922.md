# 打印与页面方向兼容性修复

## 本轮修改

| 范围 | 根因与修复 |
| --- | --- |
| Canvas 导出 | 位图替换为图片时丢失 CSS 尺寸、定位和变换，导致高分屏位图按像素宽高放大。现在保留已计算的显示盒、定位、透明度及类名，不改动原 Canvas。 |
| 页面测量 | 页面测量依赖全局 window，且未计入 content-box 的内边距和边框。改为所属文档的窗口，使用未缩放的完整页面盒。 |
| DOCX 混合纸张 | 打印规则只读取首页尺寸，横向分节和不同纸张被统一。固定分页按页生成具名 CSS 页面规则，保留文档边距，取消外层统一宽度限制。流式模式保持浏览器分页。 |
| PDF 页面方向 | 缩略图、适配和导出传入查看器偏移时覆盖了页面原有旋转。统一使用原始旋转加用户偏移，并按各页实际方向及尺寸输出打印页面。位图像素取整不再改变纸张几何尺寸。 |
| 输出就绪 | 图片 decode 等待可能绕过超时，后台窗口可能不执行动画帧。计时从等待开始即生效，清理事件与计时器；等待字体后再进行布局绘制，资源失败使用浏览器回退。 |

## 回归检查

- `pnpm test:output-compatibility`：布局盒、混排样式、全部 90 度旋转组合、加载失败及有界就绪等待。
- `pnpm verify:output-compatibility`：上述检查，以及实际 Chromium 中的 Canvas、DOCX 引擎、打印到 PDF、PDF.js Worker、缩略图、旋转、混排纸张及 JPEG2000/WASM 像素验证。
- `pnpm verify:compatibility-browser`：上一批表格、图表、分页、Markdown 和 PDF 拖拽回归。

打印测试读取 Chromium 输出的 PDF 页面尺寸，不仅检查 CSS 文本。混排 DOCX
要求保留 A4 纵向、A4 横向和 Letter 三种纸张，并拒绝额外空白页。旋转 PDF
同时验证缩略图尺寸、颜色标记方向以及打印后的逐页尺寸。

## 复测结果与边界

Word 饼图类型、嵌入图片及默认外部内容隔离已复测，未将已正常工作
的行为记为本轮修复。PDF JPEG2000 作为既有离线解码能力的回归项，不是新增
解码器。#322 的全部页脚和分页保真问题仍不能仅凭本次打印修复判定为完成。

本轮没有更改运行时依赖、版本或锁文件；没有新建 PR、关闭 issue 或修改主分支。
新增 `buildPrintPageStyle.pages` 是可选的固定页面尺寸列表，现有单一纸张调用
保持原语义。打印对话框和驱动仍可能覆盖纸张尺寸。此处验证范围不等同于全仓库
发版验收，也不代表所有 Office 文档与桌面应用像素一致。

## 回退

回退本轮功能提交即可，无数据迁移，之前的兼容性修复不受影响。
