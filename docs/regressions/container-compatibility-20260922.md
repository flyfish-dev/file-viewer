# 容器识别与幻灯片图片关系修复

## 修复

- Word 按内容识别 OLE、OOXML、Word 2003 XML、HTML 和可读文本，不再把 HTML/GBK 文本型 DOC 强制送入 OLE 解析器。
- HTML 和文本复用 Word 页面、缩放、导出和卸载生命周期。HTML 经既有文档消毒边界处理；仅保留限定在当前预览中的普通 CSS 规则，默认不加载远程资源或执行脚本。
- PPTX 识别 SVG-only 扩展图片关系，优先包内矢量资源，保留有效位图回退。缺少可选图片资源不再导致整页解析失败；不请求外链图片。

## 验证

`node scripts/verify-container-compatibility.mjs`：6 项图片关系单元测试、4 项 Chromium 集成检查。
Word 包既有 20 项测试通过；Word、PPTX 构建和类型检查通过。

两份之前缺页的演示文稿分别恢复到 2 页、3 页。12 份演示文稿在真实 Chromium 中复测图片及页面解析；逐元素视觉保真仍需独立对照，不能把能打开等同于全部版式正确。

## 边界

HTML 不执行宏、脚本、外部字体或其他主动内容；复杂 CSS 条件规则及独立资源目录不由本次转换补造。
二进制数据、未知 XML 和 RTF 不会被伪装为成功的 HTML 预览。本轮不关闭 issue、不发版，不修改主分支。
