# File Viewer 文档

File Viewer 让私密文档留在浏览器内，不依赖服务端转码链路。先选择原生组件，再按需加入渲染能力，并从自己的同源地址发布 Worker、WASM、字体与 vendor 资源。

## 文档覆盖范围

- Vanilla JS、Web Component、Vue、React、Svelte 与 jQuery 原生集成。
- 标准包、模块化渲染器、场景 Preset 与完整 Full 包。
- PDF、Office、CAD、压缩包、邮件、媒体、绘图、代码、3D 与工程格式。
- Shadow DOM 样式隔离、主题变量、工具栏定制、打印、导出与搜索。
- Docker、CDN/IIFE、私有部署、离线资源与发布验证。

## 上线前可验证

文档站输出语义化静态 HTML。每个规范页面都具备独立标题、描述、Open Graph 与 X 元数据、结构化数据、原始 Markdown 入口及中英文 alternate；搜索在浏览器本地完成，线上不依赖文档服务端。
