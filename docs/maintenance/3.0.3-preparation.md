## 本地 Demo 与文档

样例库提供 `word-revisions.doc`、`word-cover.docx`、`page.html` 和 CAD/DWF 样例。Word 设置可切换三种文本修订模式；HTML 可选择默认视图；最近打开默认收起，不遮挡 sheet 标签。操作步骤和复现命令已同时更新中文、英文 Demo/usage/格式/接入文档。

CAD 当前输出是当前视图的栅格快照，支持导出 HTML 和浏览器打印到 PDF；需要整图时先适配。不能宣称全图纸矢量转换或单独的 PNG/JPEG 下载按钮已完成。CAD 的 `captureCanvas()` 可用于引擎级快照集成，但不能把 API 等同于 File Viewer 中尚未提供的下载界面。
