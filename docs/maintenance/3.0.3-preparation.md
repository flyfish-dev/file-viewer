## 本地 Demo 与文档

样例库提供 `word-revisions.doc`、`word-native-revisions.doc`、`word-native-revisions.docx`、`word-cover.docx`、`ofd-resource-paths.ofd`、`page.html` 和 CAD/DWF 样例。Word 设置可切换三种文本修订模式；HTML 可选择默认视图；最近打开默认收起，不遮挡 sheet 标签。操作步骤、原生参考文件边界和复现命令已同时更新中文、英文 Demo/usage/格式/接入文档。

CAD 已补齐 PNG/JPEG 下载按钮，和 HTML、浏览器打印到 PDF 一样捕获当前视图；需要整图时先适配。这不是全图纸矢量转换或跨页批量出图。图片下载通过所属组件的下载钩子，同时受下载和 HTML 导出权限约束；文本/图片水印必须成功写入，资源缺失或捕获期间配置被修改时拒绝输出，打印遮罩仍仅作用于打印。320/390px 的 CAD 操作至少为 44 × 40px，不超过两行；移动端和窄弹窗工具栏已加入真实尺寸、展开/收起、搜索键盘及焦点恢复回归。中英文 Vanilla JS 接入文档补齐 Angular 标准资产复制和 baseHref 示例。
